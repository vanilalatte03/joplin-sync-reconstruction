# 공개 범위와 공개 전 검토

2026-10-23 공개를 준비했다. 이 저장소는 Joplin 공식 프로젝트와 관계없는 동기화 연구·최소 재구축 결과다. Joplin 호환 구현이나 법적 검토를 마친 배포 제품이라는 뜻은 아니다.

## 포함한 내용

- 자체 작성한 Java / Node.js 동기화 엔진과 테스트.
- 조사 과정·설계·차이·미검증 사항을 기록한 문서.
- 테스트 노트, 시나리오 결과, 동기화 로그, digest, 소스맵 위치에 대응하는 함수 이름·범위 같은 선별 증거.
- 분석을 재현하는 자체 스크립트와 잠금 파일, 원본의 출처·라이선스 고지.

개인 계정의 토큰, 프로필·DB, 바이너리, node_modules, 생성 번들, 원시 REA Evidence bundle·브라우저 스냅샷, 개인 Codex MCP 등록 파일은 게시하지 않았다. 원본 코드가 포함될 수 있는 자료는 로컬 연구 자료로 보존한다. 공개본의 로컬 경로는 `<LAB_ROOT>` 또는 `<USER_HOME>`으로 치환했다. 원본과 공개본의 해시 및 변환 범위는 `evidence/publication-provenance.json`에 기록했다. 이미지를 제외한 공개 증거는 원시 기록과 구별해서 읽어야 한다.

원본의 기본 라이선스는 AGPL-3.0-or-later이며 하위 디렉터리의 별도 라이선스가 우선할 수 있다. REA는 MIT다. 세부 사항은 [서드파티 고지](../THIRD_PARTY_NOTICES.md)에 있다. 자체 구현에 대한 별도 오픈소스 라이선스는 아직 선택하지 않았다. GitHub의 공개 접근과 제3자의 자유로운 재배포·상업 이용 허용은 별개다. 기존 서드파티 라이선스는 그대로 유지한다.

## 공개 전 검토에서 수정한 항목

1. `__proto__`라는 유효한 ID를 사용하는 노트가 일반 JavaScript 객체의 특수 setter 때문에 파일에 남지 않았다. 실패하는 회귀 테스트로 확인한 뒤, 로컬 노트 사전을 프로토타입이 없는 객체로 바꿨다. `__proto__`, `constructor`, `toString` 세 ID를 저장·재로딩하는 테스트를 추가했다.
2. 초기 실험 스크립트는 실패와 재시도 로그를 같은 이름으로 저장해 실패 로그가 덮어써질 수 있었다. 로컬에 보존된 전체 로그에서 2026-10-22 23:40:50 KST의 실제 fail-safe 중단 구간을 다시 추출했다. `destination-unavailable.log`가 그 발췌다. 재실행 스크립트는 실패/재시도 파일을 구분하고, `No errors`를 실패로 오인할 수 있는 정규식을 구체적인 오류·fail-safe 패턴으로 바꿨다.

SQL은 바인딩 매개변수를 사용하며, 쓰기·이력·응답 저장은 트랜잭션에 묶인다. 로컬 실험용 서버의 인증 부재, 무제한 이력, 단일 JVM 제약은 설계 문서에 공개했다. 원본의 전송 중 실제 네트워크 단절은 여전히 미검증이다.
